# Components

One page per component family. Variants of one component share a page. Filler stays constant across those variants. Color, fill, outline, and glow come last, as modifier classes — one example per class, not every token value.

These pages teach isolation. Combination views that already exist as labeled HTML are linked at the bottom of the matching family as swatch boards. They are not suggested servings.
